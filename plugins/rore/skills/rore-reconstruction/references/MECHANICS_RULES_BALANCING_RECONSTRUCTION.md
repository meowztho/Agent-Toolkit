# Mechanics / Rules / Balancing Reconstruction

Use for games and any system whose behavior depends on formulas, cooldowns, thresholds, resource/economy rules, scheduling, scoring or interacting state machines.

Recover:
- input/output variables and units;
- formulas/curves/rounding/clamps;
- state preconditions and transitions;
- timers/cooldowns/durations;
- stacking/precedence/order-of-operations;
- resource generation/spend/regeneration;
- AI/selection/priority rules;
- progression/economy/balancing tables;
- version/difficulty/context modifiers.

Combine static tables/code with runtime measurements. Use controlled perturbation when two plausible formulas fit normal samples. Vary one variable or boundary and observe the differential.

Do not normalize odd constants or apparent balance mistakes. They are Reference Truth unless disproven.
