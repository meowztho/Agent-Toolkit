# External / Version / Review Research

External sources are a discovery and corroboration lane, not a substitute for target evidence.

Useful source families:
- official docs/specs/API docs/help/changelog/source/history;
- public release notes and version records;
- reputable technical analysis/research;
- public walkthroughs/demos;
- reviews, issue reports, feature boards and community discussions.

Classify external claims as useful stages such as:

```text
DISCOVERY_HINT → EXTERNAL_DOCUMENTED → TARGET_CORROBORATED
```

Reviews/community reports can reveal hidden states, recurring defects, environment-specific behavior, old features, recovery semantics and version differences. Preserve source/date/sample bias; do not turn complaints into a product roadmap.

Current facts that can drift require current evidence. When offline, create a research packet of unresolved questions rather than inventing public knowledge.
