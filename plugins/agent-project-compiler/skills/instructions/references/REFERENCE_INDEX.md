# APC Reference Index — v2.35.2 Plugin-Native JIT Router

This is the canonical retrieval router for the APC Skill. It routes to procedural detail; it is not project truth.

## Routing law

```text
material decision
→ smallest canonical APC reference slice
→ required project authorities / companion procedure
→ decision or artifact
```

Installed/visible files are not loaded knowledge. Do not preload unrelated references. File count is not an architecture criterion.
